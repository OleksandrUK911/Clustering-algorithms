# Кластеризація в аналізі персоналій клієнтів

Проект з аналізу та сегментації клієнтів маркетингової кампанії за допомогою алгоритмів кластеризації.

## 📋 Опис

Цей проект виконує аналіз портретів клієнтів (Customer Personality Analysis) з використанням різних алгоритмів кластеризації. Мета - виявити різні сегменти клієнтів для покращення маркетингових стратегій та персоналізації продуктів.

Customer Personality Analysis дозволяє бізнесу:
- Краще розуміти своїх клієнтів
- Адаптувати продукти під конкретні потреби різних типів клієнтів
- Фокусувати маркетингові зусилля на найбільш перспективних сегментах

## 🎯 Завдання

На основі даних з файлу `marketing_campaign.csv` виконати кластеризацію для виявлення сегментів клієнтів з використанням різних алгоритмів машинного навчання.

## 📊 Вхідні дані

Датасет містить інформацію про клієнтів з такими категоріями атрибутів:

### Характеристики користувачів
- `ID`: Унікальний ідентифікатор клієнта
- `Year_Birth`: Рік народження
- `Education`: Рівень освіти
- `Marital_Status`: Сімейний стан
- `Income`: Річний дохід домогосподарства
- `Kidhome`, `Teenhome`: Кількість дітей та підлітків
- `Dt_Customer`: Дата реєстрації
- `Recency`: Днів з моменту останньої покупки
- `Complain`: Наявність скарг

### Продукти
- `MntWines`, `MntFruits`, `MntMeatProducts`, `MntFishProducts`, `MntSweetProducts`, `MntGoldProds`: Суми витрат на різні категорії продуктів

### Акції та взаємодія
- `NumDealsPurchases`: Покупки зі знижками
- `AcceptedCmp1-5`, `Response`: Прийняття маркетингових кампаній
- `NumWebPurchases`, `NumCatalogPurchases`, `NumStorePurchases`: Канали покупок
- `NumWebVisitsMonth`: Відвідування вебсайту

## 📈 Методологія

### 1. Підготовка даних
- Завантаження та первинний аналіз датасету
- Обробка пропущених значень (медіана для числових, мода для категоріальних)
- One-Hot Encoding категоріальних змінних
- Створення додаткових ознак (Total_Spent, Total_Purchases, Age тощо)
- Обробка дат (витягнення стажу клієнта, місяця реєстрації)

### 2. Кластеризація KMeans
- Базовий експеримент без масштабування
- Застосування StandardScaler для нормалізації
- Виявлення та обробка викидів методом IQR
- Elbow Method для визначення оптимальної кількості кластерів
- Візуалізація та аналіз результатів

### 3. Ієрархічна кластеризація
- Агломеративна кластеризація з single linkage
- Побудова дендрограми
- Аналіз різних варіантів кластеризації (2 та 3 кластери)

### 4. Альтернативні методи
- DBSCAN для кластеризації на основі щільності
- Порівняння з іншими методами

### 5. Оцінка якості
- Метрика силуету (Silhouette Score) для оцінки якості кластеризації
- Візуалізація кластерів у 2D та 3D просторі
- Статистичний аналіз характеристик кожного кластера

## 💡 Практичне застосування

Результати кластеризації можуть бути використані для:
- **Персоналізації маркетингових кампаній**: Різні сегменти отримують персоналізовані пропозиції
- **Оптимізації продуктів**: Адаптація продуктів під потреби конкретних сегментів
- **Підвищення ефективності**: Фокусування зусиль на найбільш перспективних сегментах
- **Покращення клієнтського досвіду**: Розуміння потреб різних груп клієнтів

## 📝 Основні висновки

1. **Масштабування важливе**: Застосування StandardScaler значно покращує якість кластеризації KMeans
2. **Обробка викидів корисна**: Видалення викидів забезпечує більш стабільні результати
3. **Elbow Method ефективний**: Допомагає об'єктивно визначити оптимальну кількість кластерів
4. **KMeans vs Ієрархічна**: Обидва методи дають корисні результати для сегментації клієнтів
